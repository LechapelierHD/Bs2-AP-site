## Checks / chapters / goal

- **Check** — walk up to an AP pickup, press **Use (F/E)**, the location is sent to the server.
- **Chapters** — unlocked with level tickets (Adonis → … → Inner Persephone; optional Minerva chain).
- **Goal** — receive **Escape Rapture** (placed in Inner Persephone).
